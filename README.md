#  Library Management System (Java OOP Project)

##  Project Overview
This is a simple **Library Management System** developed using **Java** and **Object-Oriented Programming (OOP)** concepts.

The system allows:
- Adding books
- Displaying available books
- Issuing books
- Returning books

This project demonstrates strong understanding of core OOP principles like Abstraction, Encapsulation, and Polymorphism.

---

##  Technologies Used
- Java (JDK 17)
- IntelliJ IDEA
- Terminal / Console

##  OOP Concepts Implemented

### 1️ Encapsulation
- Private variables in classes
- Public getter methods

### 2️ Abstraction
- Library class hides internal book management logic

### 3️ Polymorphism
- Method usage like displayBook()

### 4️ HAS-A Relationship
- Library HAS-A list of Books
